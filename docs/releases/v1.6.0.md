## LNPP 组件管理器 v1.6.0

新增 **MySQL** 组件：收 8.0.x 与 8.4.x LTS，与 PostgreSQL 对等的常驻数据库组件——初始化、改密码、建删用户、备份、还原、下载源、独立页签，全套接齐。

### 新增：MySQL 组件

mysqld 按常驻进程建模：

```
bin\mysql\<版本>\bin\mysqld.exe --defaults-file=data\mysql\<版本>\my.ini
```

- **状态灯 = 有没有属于该版本的 `mysqld.exe` 进程**，启动完成还要同时看到端口监听。Windows 上 mysqld 不写可用的 pid 文件，所以按镜像路径判定归属，不会把别处装的 MySQL 认成自己的
- **只管理 `root@localhost`**：客户端连接、备份、还原都走它；新建账号只允许 `'名字'@'localhost'`
- **初始化**用 `--initialize-insecure` 重建空数据目录，然后一次性启动、设置 `root` 密码、验证登录、再停下来。口令 DPAPI 加密存 `mysql.password.enc`
- `my.ini` **每次启动都从模板重新生成**：8.0.x 用 `etc\mysql\my.ini.tpl`，8.4.x 用 `etc\mysql\my-8.4.ini.tpl`；手工配置放同目录的 `conf.d\*.cnf`
- **版本切换不迁移数据**：切到哪个版本，就用它自己的数据目录；跨版本搬数据走「备份 → 切换版本 → 还原」
- 备份用 `mysqldump --all-databases` 写到 `backup\mysql-<版本>-<时间>.sql`；还原可选「还原前初始化」（原数据目录移 aside，可回滚）
- 客户端口令放在临时 `--defaults-extra-file`，SQL 放在临时文件，用完即删，不上命令行
- 组件下载器内置 MySQL 源：`mysql-8.0.46` / `mysql-8.4.11`，SHA256 留空待自算（没有该行时跳过校验）

### 8.4 适配（真机联调修掉的坑）

- 8.4 默认关闭 `mysql_native_password`：`my-8.4.ini.tpl` 把它打开，老客户端才能连上
- 8.4 **删掉了 `default_authentication_plugin` 变量**——写它会让初始化和启动直接 abort（`unknown variable`，8.4.11 实测），所以 8.4 模板里没有这一行；建账号一律用显式的 `IDENTIFIED WITH mysql_native_password`，不依赖服务器默认认证插件
- 附带硬化：初始化失败自动把半成品数据目录送回收站（不拦下次重试）；启动前发现端口被陌生程序占用直接拒绝；自家进程启动即死不再空等 20 秒

### 升级提示

- 附件是**压缩包**，请先解压再运行
- `bin\` 不在包内：MySQL 8.0.x / 8.4.x 的 zip 解压到 `bin\mysql\<版本>\`（需含 `bin\` 与 `share\`），或编辑 `data\packages.conf` 后用下载器安装
- 已在用的 `data\packages.conf` 不会被新版模板覆盖：要用下载器装 MySQL，请把 `etc\packages.conf.tpl` 里的 MySQL 一节复制过去
- **`data\settings.ini` 里的 `mysql.password.enc` 绑定当前 Windows 账号，换机器或换用户需要重新填写口令**
