## 附件形态的变更

- **v1.5.2 起发压缩包**（`LNPP-<版本>.zip`）。v1.5.1 及之前发的是裸 `lnpp.exe`，
  从旧版升级需要先解压。
- 压缩包里 `etc\` **只有模板**——`etc\nginx\vhosts\` 里不含任何用户站点配置，
  内网域名、绝对路径、证书路径不会跟着发布出去（见 v1.5.3 的目录布局说明）。
- 模板数量随组件增加：v1.5.4 起是 9 个（新增 `etc\php\php.ini.append` 与两个
  PHP 站点模板）。打包脚本逐个拷贝，缺一个即中止。

## 发版流程

```
package.bat            # 编译 + 打包，版本号自动取自 app.rc 的 FILEVERSION
```

产出 `dist\LNPP-<版本>.zip`，随后推送标签并创建 release。改动见 README「发布打包」。
